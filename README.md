# 手绘二维码辅助工具

这是一个帮助用户手工绘制二维码的Web应用程序。通过上传二维码图片，系统会提供详细的分步手绘指导，让用户能够准确地在纸上重现二维码。

## 功能特点

### 🎯 核心功能
1. **二维码图片上传** - 支持拖拽和点击上传
2. **智能坐标系系统** - 实时显示鼠标悬停位置的行列信息
3. **分步手绘指导** - 逐行提供详细的手绘说明
4. **多规格支持** - 支持21×21到49×49不同版本的二维码

### 🔧 技术特性
- **实时网格绘制** - 自动计算并绘制精确的网格线
- **智能图像分析** - 自动识别黑白模块
- **可视化高亮** - 当前操作区域高亮显示
- **响应式设计** - 适配不同屏幕尺寸

## 使用方法

### 1. 上传二维码图片
- 点击上传区域选择图片
- 或直接拖拽图片到上传区域
- 支持 JPG、PNG、GIF 格式

### 2. 选择二维码规格
- 根据您的二维码选择合适的规格
- 常用规格：21×21 (版本1)、25×25 (版本2)
- 系统会自动计算网格尺寸

### 3. 开始手绘指导
- 点击"开始手绘"按钮
- 系统会显示第1行的手绘指导
- 按"下一步"按钮继续后续行

### 4. 跟随指导手绘
- 每行会显示需要涂色的具体列位置
- 例如："第3行应涂色第2列、第5列和第7列"
- 当前操作行会高亮显示

### 5. 使用技巧
- 鼠标悬停在格子上可查看行列坐标
- 可调节显示大小以获得最佳视觉效果
- 随时可重置重新开始

## 技术实现

### 坐标系系统
- 基于Canvas绘制网格系统
- 实时计算鼠标位置对应的行列
- 动态调整网格大小

### 图像处理
- 使用Canvas API分析图像数据
- 灰度转换和阈值判断
- 自动识别黑白模块

### 手绘指导算法
- 逐行分析二维码数据
- 提取每行需要涂色的列位置
- 生成易懂的手绘说明

## 注意事项

1. **图片质量** - 请上传清晰的二维码图片
2. **规格选择** - 确保选择与二维码匹配的规格
3. **手绘精度** - 按照指导精确涂色每个格子
4. **顺序执行** - 建议按顺序逐行完成手绘
